# 歇一会 · RestPause

macOS 13+ 原生菜单栏休息应用。当前应用包为 Apple Silicon 构建，无第三方依赖，不联网、不录屏、不记录输入内容。

## 使用

构建后双击 `dist/歇一会.app`。菜单栏叶子旁显示距下次休息的分钟数。

菜单按「使用模式」「休息」「时长设置」「音乐」分组，退出单独置于底部。休息预告与观影提醒统一使用深绿色圆角卡片、浅绿叶子及一致的文字层级；观影提醒保留胶囊按钮。

后台每秒检查一次计时与活动状态，休息期间使用 0.25 秒间隔以保持紧急解除和音乐淡入淡出的响应；菜单栏、观影提示和倒计时仅在显示内容变化时更新。

- 默认使用 45 分钟、休息 5 分钟，菜单中可修改并保存。
- 「暂停计时」保留累计进度；「继续计时」从原进度接着计时，暂停期间不累计，也不会因锁屏或熄屏通知清零。观影模式的延后提醒同样保留剩余时间；已开始的休息仍按原定时间结束。
- 普通模式首次键鼠活动后开始计时。连续 1 分钟无键鼠操作时菜单栏显示“空闲”，但仍继续累计；连续无操作达到休息时长（默认 5 分钟，从最后一次操作算起）直接清零，持续空闲保持为零，下一次操作开始新一轮。未达到清零时长就恢复操作，会保留全部累计时间；清零前达到使用时长，仍按普通规则进入休息遮罩。
- 菜单中开启「观影模式」后忽略键鼠空闲，持续累计观看时间；菜单栏显示「观影」。达到设定时长只显示不抢焦点的提醒，不自动遮罩或播放音乐。手动暂停影片后点击「开始休息」，才进入遮罩；「10 分钟后提醒」保留累计时间，再观看 10 分钟后提醒。提醒未处理时继续累计，不算作休息。
- 观影模式下锁屏、熄屏、切换用户和睡眠仍暂停，离开足够久会清零。休息结束后保持观影模式；可从菜单手动关闭，重启应用默认回到普通模式。关闭观影模式后按已累计时间恢复普通规则，若已达到阈值会进入休息。
- 屏幕自动熄灭、锁屏、切换用户或电脑睡眠时暂停；持续达到休息时长后清零，短暂离开则保留进度。屏幕休眠和当前控制台会话同时通过系统状态查询兜底。
- 普通模式提前一分钟显示提示。休息遮罩覆盖所有连接的显示器，限制普通应用切换和键盘输入。
- 休息时申请防止系统自动空闲睡眠，结束或退出后释放。不会暂停进程、断网或主动锁屏。手动睡眠、合盖和系统电源紧急措施不在防止范围内。
- 点击“预览遮罩”体验 10 秒，结束后保留原计时进度。
- 每次休息或预览随机显示一组文艺短句与休息提示，共 24 组，连续两次不重复；同次休息的所有屏幕使用同一组文案。
- 内置 4 首舒缓钢琴／吉他纯音乐，完全离线播放：Clear Air、Pepper’s Theme、Meditation Impromptu 01、Avec Soin。每次休息或预览随机选曲，一轮播完再重排，避免连续重复；单曲结束自动接下一首。
- 音乐默认开启、音量 25%，菜单可关闭或选择 15%／25%／40%，设置自动保存。开始时最多 3 秒淡入，结束前 2 秒淡出；紧急解除和退出立即停止，锁屏、屏幕休眠或系统睡眠时暂停。多屏共用一个播放器，不修改系统音量。
- 音乐由 Kevin MacLeod 创作，来源和 CC BY 4.0 署名保存在应用内，可从「音乐来源与署名」打开。
- 紧急解除：按住画面上的按钮 3 秒，或同时按住 Control + Option + Command + Escape 3 秒。
- 保留 macOS 系统强制退出作为异常恢复途径。本工具是自律辅助，不是不可绕过的系统锁。

## 边界

依赖前台键鼠的 GUI 自动化可能受影响；桌面共享和录屏可能包含遮罩。普通模式下，无输入是离开的推断：长时间静静阅读或看视频也可能被算作休息，可手动开启观影模式；应用不会自动识别或暂停播放器。自动化生成的键鼠事件也可能影响系统空闲时长。退出/重新启动会重置本轮进度及观影模式；时长和音乐设置保留。不默认添加开机启动。

## 构建

使用本机现有 Apple Command Line Tools，不需要下载依赖：

```sh
swift run RestCoreChecks
swift run RestPause --activity-check
swift run RestPause --music-check
swift run RestPause --viewing-check
swift run RestPause --pause-check
swift run RestPause --performance-check
zsh Scripts/build.sh
```

构建输出在项目内的 `dist/歇一会.app`，使用本地 ad-hoc 签名，未进行 Developer ID 公证。

图标源文件为 `Resources/AppIcon.png`；构建脚本使用 macOS 自带的 `sips` 和 `iconutil` 生成各尺寸图标并打包，无需额外依赖。
